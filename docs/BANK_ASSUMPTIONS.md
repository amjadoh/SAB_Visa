# افتراضات وحدود الحساب

راجعت المراجع العامة بتاريخ 2026-10-27، والصيغ الواردة في صور رسائل مخصصة للفهم داخل جلسة التطوير. لم تنسخ الصور أو أرقام الحسابات أو التجار أو المبالغ أو رموز التحقق إلى المستودع.

| الموضوع | ما يدعمه الدليل | قرار التطبيق وما يحتاج مطابقة |
|---|---|---|
| أصل الأقساط | [أسئلة SAB الشائعة](https://www.sab.com/en/personal/help-and-support/faqs/) و[برنامج أقساط](https://www.sab.com/en/personal/compare-credit-cards/sab-aqsat-installment-plans/sab-aqsat-program/) يشرحان حجز أصل التقسيط وتحرير الحد مع سداد الأقساط | نحجز الأصل المتبقي، ولا نحرره بمرور الوقت. توزيع السداد الفعلي إلى الأصل يدخله المستخدم بعد التحقق. |
| كشف يوم 10 | طلب المستخدم هدف التخطيط يوم 10؛ أحد قوالب الكشف المرجعية لا يثبت هذا كتاريخ إصدار | إعداد مستقل قابل للتعديل؛ الاستحقاق من الكشف، لا يحسب بإضافة مدة مفترضة. |
| السداد | القوالب تعرض طلب تسديد وتأكيد سداد منفصلين | نستخدم التأكيد، ونرفض تسجيل عملية شبيهة خلال خمس دقائق إلى أن تراجع. ليس هذا معرّفاً مصرفياً عالمياً للمعاملة. |
| مكافأة نون | القالب يذكر وجهة محفظة نون | ليست استرجاعاً إلى رصيد البطاقة وتستبعد من الدفتر. |
| رصيد إشعار الشراء | القالب يحتوي مبلغ شراء ورصيداً منفصلين | الاستخراج منفصل، ويستخدم الرصيد للمقارنة بعد موافقة المستخدم، لا يعيد بناء دفتر مفقود. يلزم تأكيد دلالة «الرصيد» مع البنك. |
| المبلغ المستحق | قالب الكشف لا يسمي المبلغ صراحة «كامل رصيد الكشف» | التسجيل يتطلب مراجعة كشف البنك؛ لا ندعي أن سداده يضمن تجنب الرسوم. |
| الرسوم والأرباح | تختلف الخطط والشروط؛ بعض صفحات الأسئلة تجمع منتجات مختلفة | لا نعمم رسوماً أو نسباً أو شروط سداد مبكر على جميع المنتجات. القسط المعروض أصل فقط؛ الرسوم تسجل منفصلة. |
| عملة أجنبية | صور الشراء المتاحة بالريال | لا تحويل عملة مفترض؛ المبلغ المرحل بالريال يحتاج إدخالاً ومطابقة. |
| نشر SMS | [سياسة Play](https://support.google.com/googleplay/android-developer/answer/10208820?hl=en) تتضمن استثناء إدارة الأموال الخاضع للمراجعة | لا نشر تلقائياً ولا ادعاء قبول المتجر. اللصق اليدوي يبقى متاحاً. |

إجمالي الدين في التطبيق يجمع الدين غير المقسط والأصل المقسط المحجوز. قد يختلف تعريف إجمالي الرصيد في كشف البنك الذي يدرج الأقساط المستحقة فقط. لذلك يقارن التطبيق **المتاح في التاريخ نفسه**، ويعرض الكشوف كالتزامات مستقلة دون إضافتها للدين ثانيةً.
