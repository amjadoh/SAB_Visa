# سجل التحقق

نسخة متابعة تلقائية قيد فحوص Android النهائية. لا يوجد نشر APK إنتاجي.

## محلياً بتاريخ 2026-10-27

- نجحت **51 حالة اختبار** للحسابات والمحلل والتسجيل الآلي باستخدام JDK 17 ومترجم Kotlin محلي؛ يعاد تشغيلها عبر Gradle في CI.
- غطت الاختبارات: بناء الخطة من التأكيد واستبعاد الإعلان، الصيغ ISO والإخفاء قبل/بعد رقم البطاقة، الإيداعات، عدم تكرار الرصيد، توزيع القسط مرة في الشهر، السداد الجزئي والمتأخر، الخطط المتعددة، الترتيب الزمني، الاستيراد المتكرر، تحرير الأصل، تعديل الحد بتاريخه، والاحتفاظ بالعمليات السابقة.
- أُجريت مطابقة محلية مصرح بها على رسائل SAB تاريخية، دون حفظ OTP أو نصوص الحسابات في المشروع أو نقلها إلى GitHub. قورنت نتائج أصل الخطة والمتبقي وعدد الأقساط بالمعلومات التي قدمها المستخدم. آخر SMS لا يثبت رصيد اليوم.
- فُحصت الملفات بحثاً عن المعرفات والمبالغ المرجعية الشخصية، ولم تضاف إلى المصدر أو الاختبارات.

## Android

تضاف روابط نتائج GitHub Actions بعد اكتمال البناء وLint واختبارات التخزين والواجهة. نتائج النسخة السابقة لا تُعد دليلاً على نجاح تغييرات هذه النسخة.

اختبار قراءة بيانات SMS عبر USB على جهاز مصرح به لا يثبت أن مستقبل التطبيق والإشعارات والأذونات تعمل على جهاز فعلي؛ ذلك يحتاج تثبيت النسخة المفحوصة وتجربتها. لا تعتبر نتيجة حدث أو بناء دليلاً على ظهور تنبيه فعلي.

## حدود مالية

يوم 10 قاعدة تخطيط وتخصيص اختارها المستخدم. يلزم مطابقة كشف البنك الحالي قبل أي ادعاء بتجنب الأرباح أو معرفة كامل المستحق. توزيع الدفعة داخل التطبيق لا يغيّر طريقة توزيع البنك لها.
